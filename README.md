# AIプロンプトメーカー(MVP)

質問に答えるだけでAIへのプロンプトを作成できるWebアプリです。

## 動かし方

### 1. 依存パッケージのインストール

ターミナルでこのフォルダに移動して、以下を実行してください。

```
npm install
```

### 2. APIキーの設定

1. `.env.local.example` をコピーして `.env.local` という名前で保存する
2. https://aistudio.google.com でGemini APIキーを発行する
3. `.env.local` の `GEMINI_API_KEY=` の後ろに発行したキーを貼り付ける

`.env.local` は `.gitignore` に登録済みなので、GitHubなどには公開されません。
絶対にAPIキーをコードに直接書き込んだり、`.env.local.example` に書いたりしないでください。

### 3. 開発サーバーを起動

```
npm run dev
```

ブラウザで http://localhost:3000 を開くと動作を確認できます。

### 4. 動作確認の流れ

1. トップページでカテゴリ(例: ゲーム制作)を選ぶ
2. 「何をしたいですか？」に入力する(例: Robloxでゲームを作りたい)
3. 回答スタイルを選ぶ(複数選択可)
4. 「プロンプトを生成」を押す
5. 生成されたプロンプトの「コピー」ボタンを押して、ChatGPTやClaudeに貼り付けて使う

## エラーが出たときの確認方法

- ターミナルに赤い文字でエラーが出ていないか確認してください。
- `GEMINI_API_KEY`が設定されていません というエラーが出た場合は、`.env.local` の設定を見直してください。
- ブラウザの画面が真っ白になる場合は、ブラウザの開発者ツール(F12キー)の「Console」タブにエラーが出ていないか確認してください。
- `npm run dev` を実行しているターミナルを一度 Ctrl+C で止めて、再度 `npm run dev` を実行すると直ることもあります。

## フォルダ構成の概要

- `app/` … 画面とAPI(サーバー側処理)
- `app/api/generate-prompt/route.ts` … プロンプト生成のサーバー側処理(APIキーを使う場所)
- `app/api/improve-prompt/route.ts` … プロンプト改善のサーバー側処理
- `lib/ai/provider.ts` … どのAIサービスを使うか切り替える窓口
- `lib/ai/gemini.ts` … Gemini APIを実際に呼び出す処理
- `lib/categories.ts` … カテゴリの一覧(追加はここに1件足すだけ)
- `lib/templates.ts` … テンプレートの一覧(追加はここに1件足すだけ)
- `lib/storage.ts` … 履歴・お気に入りをブラウザに保存する処理
- `components/` … 画面の部品(ボタンやカードなど)
